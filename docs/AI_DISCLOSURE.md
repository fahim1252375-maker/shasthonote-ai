# AI use and authorship transparency

DSH Hacks V2's retrieved rules explicitly allow AI use. Do not claim this project used 0% AI or attempt to hide AI assistance. Keep a truthful record of the actual tools and contributions used during development.

A submission should distinguish:

- **Human decisions:** the problem framing, target users, feature priorities, acceptance criteria, design choices, testing performed, and final decisions that the participant personally made.
- **AI-assisted work:** code suggestions, debugging help, documentation drafting, test ideas, interface iteration or other assistance actually used.
- **Human verification:** which commands were run, which flows were manually exercised, what failed, what remains unverified, and any limitations discovered.

Suggested disclosure template (edit to match what actually happened):

> AI tools were used as development assistance for selected implementation, debugging, test design and documentation tasks. I chose the healthcare problem and product direction, reviewed and adapted generated suggestions, and am responsible for the final code and claims. I separately tested the flows listed in the project README; anything not tested is identified as a limitation. No clinical validation is claimed.

Do not use this template unless it accurately describes the actual process. Preserve relevant prompts, decisions, code review notes and test output as evidence if the organizer requests them.
